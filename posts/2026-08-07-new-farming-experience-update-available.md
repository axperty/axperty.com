### What's New

These are all the new features added to version 26.08.07 of the Farming Experience modpack:

- Added Amendments mod.
- Added Better Than Mending mod.
- Added Better Villages mod.
- Added Cats Don't Care mod.
- Added Chunks Fade In mod.
- Added Fog mod.
- Added Hold My Items Reforged mod.
- Added Naturalist mod.
- Added Overweight Farming mod.
- Added Raised mod.
- Added Ribbits mod.
- Added Subtle Effects mod.
- Added Tiny Takeover Backport mod.
- Added Fresh Animations: Player Extension resource pack.
- Added Modded Omelet: Modern Spawn Eggs resource pack.
- Added Redstone Torch Backport resource pack.
- When the player dies, instead of losing their whole inventory, they will now lose a heart, which can be recovered by eating a golden apple.
- Phantoms don't spawn anymore.
- Zombies are now scared of any light source, this includes sources like torches, lanterns, lava, and many others.
- Zombies, skeletons, endermen, and witches now spawn exclusively in the overworld.
- Movement speed for zombies has been increased.
- Creepers and spiders now spawn exclusively in caves.
- All monsters have less health, making the difficulty more balanced.
- Untamed cats don't run away from the player anymore.
- TNTs can be thrown away when the player has a TNT block and flint and steel in their hands, press sneak and right click to throw.
- Minecarts can now be placed without rails.
- New multijump enchantment for boots, allowing the player to double jump or triple jump depending on the enchantment level.
- New dash enchantment, allowing the player to dash quickly to the direction that the player is looking.
- New smash enchantment, allowing the player to break the ground when holding a mace.
- Items and blocks crafted with dyes can be placed in water cauldrons to wash them back to their base color.
- Tools and weapons can now be always repaired.
- Days and nights are now twice as long.
- Mobs now only drop loot and XP when killed by a player, this feature disables all passive mob farms that don't require the player to manually kill mobs.
- Endermen drop significantly less XP to discourage XP farms as well.
- If you don't like any of these features, they can be easily disabled in game options.
  - Go to Options... > Mods... > Farming Experience Core > Config...

### Additional Features

- Farming Experience Core which brings many of these features will now detect if the player is actually running the modpack. If you have issues with this feature, please report the issue as soon as possible.

Some functionality added to Farming Experience Core was inspired from these great creators:

- Matcha Flavoured datapack by klei_wright.
  - Player loses a heart when they die, and they can get it back by eating a golden apple.

- Adding Features to Minecraft That Just Make Sense video by Nekoma.
  - Expanded cauldron functionality, allowing the player to wash wool, terracotta, stained-glass, concrete, concrete powder, and candles.
